# TestPlan App (lightweight)

This app provides a minimal UI to fetch a JIRA issue and generate a Formal Test Plan using a GROQ/OpenGPT API.

Quick start:

1. Install server deps:

```bash
npm install
```

2. Install client deps:

```bash
npm run install:client
```

3. Copy `.env.example` in `server/` to `.env` and fill values.

4. Run in development:

```bash
npm run dev
```

Open the client at the Vite dev URL (typically http://localhost:5173).
