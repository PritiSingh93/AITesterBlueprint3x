Jira QA Crew

Reads a Jira ticket and produces a test plan, test cases, a traceability matrix and Playwright automation — with every requirement traced back to the words in the ticket.

How it works

1
Jira Analyst Extracts requirements and acceptance criteria, each quoting the ticket line it came from and labelled EXPLICIT, INFERRED or ASSUMPTION.
2
Test Plan Writer Produces a twelve-section plan: scope, strategy, environments, entry and exit criteria, risks.
3
Test Case Writer Writes cases with steps, data and expected results, each tracing to the requirements it covers.
4
Playwright Coder Generates TypeScript specs, and states plainly when they need URLs or selectors before they can run.

What keeps it honest

Jira facts are never generated

The ticket is fetched by Python before any agent starts. No field comes from a model.

Gaps are recorded, not filled

Missing selectors, URLs or test data are listed as gaps rather than invented.

Coverage is computed

Traceability is calculated in Python from validated objects. A model grading its own output is not evidence.

Readiness is stated

Generated automation is labelled as a scaffold when it is one, instead of being passed off as runnable.

The agents have no tools

Ticket text asking to read another issue has nothing to act on — it is unreachable, not merely refused.

Deterministic validation

Python checks catch hard-coded environment URLs and credentials in generated code.

Engineering notes

  • Per-request token ceiling. The provider meters prompt + max_tokens against one limit, so each stage clamps its output budget and inherits only the context it needs.
  • Partial work is kept. When a later stage fails, the stages that finished are preserved and downloadable rather than discarded with the error.
  • A metric that lied. The traceability matrix once reported 100% coverage while mapping every case to every criterion. Fixing the match immediately surfaced a real gap.
The live demo runs in demo mode: tickets come from sample files rather than a Jira site, and every artifact is labelled FIXTURE. The four agents do the real work.
